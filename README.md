## Бүтээлч санаа

Энгийн доош гүйлгэдэг хуудасны оронд миний зураг дэлгэцийн голд, **физиктэй бөмбөлгүүдийн** дунд байрлана.
Портфолиогийн хэсэг бүр нэг бөмбөлөг: зочин бөмбөлгийг **чирж, шидэж** болно, бөмбөлгүүд хоорондоо мөргөлдөж ойно.
Бөмбөлөг дээр **дарахад** тухайн хэсэг бөмбөлгөөс томорч буй тойрог анимэйшнтайгаар нээгдэнэ.

Нэмэлт жижиг санаанууд:
- Ур чадварын жижиг бөмбөлөг дотор түвшнийх нь хэмжээгээр "шингэн" дүүрсэн; дарахад дэлгэрэнгүй гарна
- Ур чадварын хуудас: SVG тойрог хэмжүүр (`stroke-dashoffset`), тоо 0-ээс өсч тоологдоно
- Миний тухай: зургийг тойрон эргэлддэг бичиг (SVG `textPath`), сонирхол, боловсролын он дараалал
- Бүтээлүүд: сайтын холбоос, GitHub, багш нэвтэрч үзэх туршилтын эрх
- Бөмбөлөг дарахад "blop" дуу гарна (том бөмбөлөг = бүдүүн дуу) — Web Audio API, дууны файлгүй
- Харанхуй / цайвар горим, `localStorage`-д хадгалагдана
- Нууц: **миний зургийг давхар дараарай** 💥
- Гараар (Tab + Enter) ашиглаж болно, тоглохыг хүсэхгүй хүнд энгийн цэсний товчнууд бий

## Физик хэрхэн ажилладаг вэ (script.js, 4-р хэсэг)

Бөмбөлөг бүр `<button>` бөгөөд байрлал `x, y`, хурд `vx, vy`, радиус `r`, жин `mass` гэсэн өгөгдөлтэй.
Секундэд 60 удаа (`requestAnimationFrame`) `step()` функц:

1. **Пүршний хүч:** бөмбөлөг бүрийг төв рүү татна: `vx += (centerX - x) * SPRING`
2. **Үрэлт:** `vx *= 0.955` — бөмбөлөг аажмаар удааширна
3. **Мөргөлдөөн:** хос бүрийн хувьд `зай < r1 + r2` бол давхцсан гэсэн үг →
   хооронд нь түлхэж салгана (хүнд нь бага хөдөлнө), төвүүдийг холбосон шугамын дагуу хурдыг нь ойлгоно
4. **Хана:** бөмбөлгийг талбайн дотор барьж, хурдыг эсрэгээр нь эргүүлнэ
5. **Зурах:** `transform: translate(x, y)` — товч бүрийг шинэ байрлал руу нь зөөнө

**Чирэх:** `pointerdown` бөмбөлгийг барина, `pointermove` курсортой хамт хөдөлгөнө, `pointerup` үед сүүлийн
хэдэн байрлалаас шидэх хурдыг тооцно. 6px-ээс бага хөдөлсөн бол дарсан (click) гэж үзнэ.

## Файлын бүтэц

```
index.html      хуудасны бүтэц (танилцуулга, бөмбөлгийн талбай, цонх)

```
